# صرافة بشار

تطبيق ويب للموبايل (PWA) لإدارة الحوالات والأرصدة وكشوف الحسابات. البيانات محفوظة على Supabase ومحمية بتسجيل دخول.

- `index.html` التطبيق كامل.
- `config.js` رابط Supabase والمفتاح العام (آمن بالمتصفح، الحماية عن طريق RLS).
- `supabase/migrations/` بنية قاعدة البيانات.
- `sw.js` و `manifest.json` لتثبيت التطبيق على الشاشة الرئيسية.

التثبيت على آيفون: افتح الرابط بـ Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
على أندرويد: افتح الرابط بـ Chrome ← القائمة ← «تثبيت التطبيق».
